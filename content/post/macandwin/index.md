## 在此之前 我的设备

很明显，这文章不只是为了记录买个笔记本和卖个笔记本，反而更像是我的买电脑记

在买这台 MBP 之前，我一直坚守 Windows 阵营 (除了中途有几次日用 Arch 外)

2025 年的暑假买了台最顶配的 Legion R7000P，配的 5060+64G 内存，完全足够胜任我的游戏与日常工作

![alt text](https://genmin.icu/p/macandwin/IMG_20260925_005304_compressed.jpeg)

**她很好**，到了 2026 年的今天依然是很顶级的配置，但是我不是很喜欢她

我日常打的最多的游戏只有 CS2 + 崩铁，在最空闲的暑假，也不过是后台开俩游戏挂机罢了

对我而言，电脑是工具，好不好看无所谓，出门都是带上我的手机和平板足以胜任工作，不会存在任何美感的需求

Legion 很厚重，非常厚重。噪音倒是还行，和旁人的游戏本比起来也还算小，我倒不是很关心这方面

在 Legion 之前，我用的是 RedmiBook Pro 15 2022 的锐龙版，妥妥的全能本，不算轻薄，不算厚重，到现在看实在不入眼

## 为什么我需要一台 Mac

如上，一个是因为我对 Legion 有点审美疲劳，内在还行外在实在是太稳重，感觉也和很久很久以前的笔记本大砖头没啥区别

另一个是因为我已经一年没换设备了，刚好买个 MBP 玩玩

我上一次接触来自苹果的设备，还是我妈用过的上古 iPhone 8 Plus，当时用它打《原神》，流畅度印象非常深刻

别人常说，`买 MBP 就是买屏幕、音响、键盘、触控板送芯片`，我买之前也只是笑笑，我是拿来干活的，不是拿来娱乐的，这不重要

当然，还有一个不算那么重要的原因就是想体验一下*苹果的 AI 推理能力*，不过我不是喜欢端侧大模型的人，这也不重要

我的需求就一句话: `能带出门，不用一堆外设`

选择 M1 Pro 芯片是最正确的一个选择，往下选只有 M1，对于我这种超高强度使用电脑的人**绝对是不够**的，往上选同性能的要到 M4 普通版，都快能再买一台 Legion 了

我选的是 32G 内存的版本，本人有严重的内存焦虑，都是被 Windows 害的。与我眼中 Windows 低于 32G 的机器开俩浏览器都能卡，日用绝对不可能

## 有了 Mac 之后...

总结: **我的下一台电脑，必须只能是 MacBook**

### 新鲜劲

电子产品的 `三分钟热度` 绝对不止三分钟，嗯

这股新鲜劲的来源其实不是设备本身的吸引力 (比如新功能 / 以前没有的东西)，而是从 Win 转到 Mac 的适应问题

最大的问题之一绝对是 Command / Control 等键，在 Win 上包括我在内的大部分人都是用左手小拇指按下的，Mac 的逻辑是用大拇指按下的，适应下来至少要你**有意识地修正你的操作**大概一个星期

其他的操作很容易适应，比如触控板的确认是要用力按下的这种稍显不同的，很快就适应的

### 触控板

其实在用 MBP 的触控板之前，我都不知道触控板是可以做到每一个区域都可以按，且具有如此*丰富*且*带有爽感*的反馈的

Win 的笔记本也许有类似的技术，但我没买过，一开始的时候我用 Mac 笔记本都是 轻触而不按下，还闹了个笑话，纯属农村人进城了

很多人喜欢三指拖拽的这个功能，在我这误触率非常之高，不知道是不是我的问题

### 键盘

我的这台 MBP 键盘手感说实话真不太行，不知道是不是上任机主的问题

按键手感不能说很好，也不能说很差，对于天天打机械超大键程的人来说，聊胜于无

### 屏幕

我得夸，真得夸

3456 x 2234 120Hz ProMotion 的 Liquid 视网膜 XDR 显示屏 (定语是不是太多了)

ProMotion 真的是很牛逼，加上 MacOS 的神秘优化，和我用过的任何一台 Win 机器都不一样，我也不是很说得出来是什么感觉，大抵是字体或者锐化方面的差别，建议你线下去实体店浏览网页看看

这块屏幕在没被卖掉之前，是我家除了分辨率不及电视之外，刷新率不如电竞显示器之外，屏幕素质最好的

好到什么地步呢？我的 Avata 360 和 Lumix S5 素材只有在这块屏幕上看*才能展现出*原有的风格。配合上超高的亮度 (1600 nits)，绝对不是所谓拉饱和度和亮度就能调出来的

### 性能

要知道 M1 Pro 已经是 5-6 年前的处理器了，而且还是移动端的 (笔记本，貌似苹果不太分这玩意)，轻度剪辑 / 重度代码 / 日常软件 绝对胜任

拿到机器我做了个极度不可参考的测试，但是也足够表现出其性能之好了:

![alt text](https://genmin.icu/p/macandwin/59438042-1684-462F-AF74-328624B3B365.png)

用这两台机器同时编译 NodeGet 项目，用时都为 2m 11s:

- MacBook Pro M1 Pro + 32G
- Legion R9 8945HX + 64G

虽然这完全就几乎没有可比性，甚至每个平台的依赖都有区别，这不重要，依旧可以看出来她很能打

### 续航

这个也是我买 MBP 的理由之一，出门不用带大砖块了

一天一充，不管干啥，看片还是 Coding 或是放歌，都没毛病

而且 TypeC 的笔记本就是好啊，随便找个 PD 头子都能用

#### Coding

生产力工具，当然就是要干活

不论是在 Win 还是在 Mac，IDE 都是 RustRover，说实话真没啥区别，除了触控板顺手很多

在 Win 认真坐下来半天写代码，不接键盘和鼠标不可能的，而且还有续航方面问题，基本只有在家能打打

Mac 给了我随时随地码东西的勇气。这期间我着重参与的项目 NodeGet 的代码量 90% 都是从这台机器上产出的；我的博客在我有 Mac 的这几个月内都是从 Mac 产出的

也许我还在有了新电脑的 `三分钟热度` 里面，也有可能是因为确实 Mac 效率高，又或者是因为暑假太闲了

如果你用 Mac 来编程，确实体验会比 Windows 好很多，至少一切都是你熟悉的类 Unix，没有那么多奇奇怪怪的问题

#### MP4

和 MP3 差不多，MBP 得益于优秀的屏幕与扬声器，成了我在暑假**最重要**的追番工具

其实很好理解，体验确实不错

#### 游戏

emm，Mac 玩游戏在现在仍旧是一个具有 `精神病史` 的问题。不过你都买 Mac 了，谁拿来打游戏呢？

不过现在 Mac 玩游戏早就有一堆方案了，手游端游都有对应的模拟器 / 虚拟机 / 兼容层，包括但不限于 Win / 安卓 / iOS / Switch 等等等等，一些知名的模拟器十万年前都有 Apple Silicon 支持了

我自己也曾经尝试了运行 iOS 端的崩铁，流畅游玩，但是操作 / 映射麻烦，不管了

### 使用方式

MBP 确实是艺术品，也不过是好看点的工具罢了

MBP 内置有散热，而且本身 Apple Silicon 发热也是众所周知的不高 (即使如此 M1 Pro 还是 Apple Silicon 系列中能耗比最低的)

我都是直接放在床上，很多时候都是趴着用的。我可以这么说，在绝大多数环境下，这台机器在被子上这种极端不利于散热的环境下，都可以靠备用散热撑过去

当然不建议这样用哈

以前 Legion 太重而且发热巨大，放床上两分钟你的笔记本和床总有一个得烧起来，不可能的

我带 MBP 出门最多的是去图书馆，确实也是因为她不需要太多的外设，最多的最多就是一根电源线，极度适合作为 BGM Player 和消息回复啥的工具

## 为什么我要卖掉 Mac

这个问题很多原因，我其实也不怎么分得清哪个是主要的

### 体积与重量

不要以为 MBP 很便携，真的很重！

作为一个 16 inch 的笔记本，还有这么多的外围配件，体积和重量都是不小的，比我 RedmiBook 全能本还重很多

我也没称过，不过肯定的是违背了我想便携的初衷

### 性能

上面说编译性能持平，确实是在某个特定环境下的情况，过去了五年了，性能肯定打不过现代的 CPU / GPU

花近 6K 买到的是一个性能绝对配不上价格的产品，全新在这个价位能在轻薄本市场随便买，某些地方可能还比 MBP 好不少

### 价格

这是优点，也是缺点

你也可以看到我的电脑以 5938R 买的，5660R 卖的，100 天过去了只掉了 300R 不到，如果是闲鱼出手肯定比这个价还高，太保值了

五年前的东西到现在依旧有高昂的价格，保值率和保值周期超级长，这也是 Mac 的常态了

这也导致你如果要入手 Mac 二手货，面临的问题也挺大的

我仍然建议你频繁地更换设备，每个周期中自己加点钱上新设备，尤其在 Mac 方面

### 学业

从一个监狱走到第二个监狱了，上了高中才发现一周要上六天课，还不能回家，带台 Mac 去高中也不太现实，平常也玩不到

### MacOS

我在优势中没有夸 MacOS，因为我一开始用的就是 MacOS 26，很多人喷这玩意 Bugs 越来越多。由于我没有参照的对比版本，多不多我们先不论，就论这个体验

MacOS 在运行一些风险 (我也不知道形容对不对，就是虚拟机软件，譬如 Wine / PD) 较高的软件时，会忽然卡死，触控板无法按压 (像一块石头)，鼠标动不了，然后只能长按电源键重启

很搞人心态这玩意，第一次遇见的时候我以为我电脑爆炸了，气死我了

MacOS 还有一些小功能对于初次使用者来说就是黑箱，不像 Win 上这么了然于胸，间接导致了效率低下

### Win 已足够

有了几乎顶配的游戏本，再去买个弱鸡的 Mac 貌似不太说得过去，虽然确实很好用

还是老生常谈的生态问题，印象最深刻的是本来想借助 M1 Pro 强大的图形性能帮我从航拍照片中三维建模学校的，但是无奈于没有任何软件可以用，放弃了

Win 永远就是不好用，但是保底足足的选择，没有之一
