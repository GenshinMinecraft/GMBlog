### 启程

原先，我是一个在各种语言中混迹的小白，曾经使用过 `Python` / `Go` / `CPP`，甚至是基于图形化编程的 `Mind+`

直到我知晓了 `Rust`......

今年的六月份，我开始了我的 Rust 学习旅程，与其他人学习 Rust 感到不同的是，我的 Rust 学习旅程*竟然惊人的顺利* (?)

也许是因为有其它语言的基础，以及 Rust **非常符合我的编程直觉**，从那以后 Rust 就成为了我的**主力语言**

于是我尝试编写了一个基于 Rust 的 [Cloudflare Workers AI Bot](https://github.com/GenshinMinecraft/Rust-Cloudflare-Workers-AI-Telegram-Bot)

相关文章可参考: [200 行 Rust 代码实现简单 CF Workers AI Bot | Rust 学习日记](https://c1oudf1are.eu.org/p/rustcfwksaibot/) / [搭建属于自己的 Cloudflare Workers AI Telegram Bot](https://c1oudf1are.eu.org/p/makerustcfwksaibot/)

令我震惊的是该项目竟然在 Github 获得了 45 个 Stars，这对一个编程新人来说无疑是巨大的鼓励

### 扬帆

随后，我又去和朋友一同编写了[分布式 Cloudflare IP 测速器](https://github.com/GenshinMinecraft/CloudflareSpeedtest-Slave)，也就是批量优选 IP，我负责后端，也就是测速端的编写

有关文章: [搭建 Cloudflare Speedtest 后端](https://c1oudf1are.eu.org/p/cfst/)

虽然该项目已经基本死翘翘，无人维护，但是他给了我很多启发: 
- 合作项目 tm 一定要先**沟通好**再下手
- **gRPC YYDS**
- 永远不要让*附属功能*比*主要功能*实现更大

### 远航

有了上面一些项目的经验，我已经基本可以开发一些高级的 Rust Cli 程序了 (PS: 此处 "高级" 指的是语言层面的高级)

先后写了:
- [哪吒第三方监控端](https://github.com/GenshinMinecraft/nezha-agent-rs): [相关文章](https://c1oudf1are.eu.org/p/nezha-agent-rs/)，因为上面的测速项目使用的是 `gRPC` 通信，而 Nezha 也是基于此
- [Cloudflare Workers KV SDK](https://github.com/GenshinMinecraft/cloudflare-workers-kv-sdk-rs): [相关文章](https://c1oudf1are.eu.org/p/cloudflare-workers-kv-sdk-rs/)，第一次尝试编写 Lib Crate，仅仅只是一些简单的 HTTP 请求，用于读写 `Cloudflare Workers KV` 内容
- [Akile Monitor 第三方监控端](https://github.com/GenshinMinecraft/ak_monitor_client_rs): [相关文章](https://c1oudf1are.eu.org/p/akile-monitor-client-rs/)，和哪吒的差不多，仅仅只是把 gRPC 换成了 WebSocket，并且了解了一些缩小 Binary 大小的方法
- 更多未公开项目...

来年的愿望就是深入 Rust，理解其各个系统的相关实现，为此我还特意买了一本 《深入 Rust 标准库》

### 博客

今年，该博客经历多次更改域名、更改所有权等重大改变，但无伤大雅

今年共产出博文 46 篇，平均约 8 天 / 篇，内容多为技术类或教程

最长的文章乃 [DN42 最简教程](https://c1oudf1are.eu.org/p/dn42/)，Markdown 文档共计 4124 个字数，20420 个字符；包含：2947 个汉字、211 个标点(全角)、12927 个字母、1177 个数字

但由于所有权的转移，来年的博文产出速度会下降很多，方面也逐渐变得广泛，但还是无伤大雅

关于这个博客，我一直都是以记录日常折腾内容为主

不会有多少人看，也不会有多少流量，全年在 Google 流量不超过 5000，Bing 也不会超过 1W，且由于频繁更换域名，收录较少

其实该博客仅为一个收录平台，主要发布于 Nodeseek 论坛以及其他的论坛，受众面基本为 MJJ / 技术实力较高的用户
